# Softmax

This project implements the Softmax activation function from scratch using NumPy.

## Description

Softmax converts a vector of numbers into probabilities.

The sum of all output probabilities is always equal to 1.

## Formula

softmax(x_i) = e^(x_i) / Σe^(x_j)

## Example

Input:

[1, 2, 3]

Output:

[0.09003, 0.24473, 0.66524]

Sum:

0.09003 + 0.24473 + 0.66524 ≈ 1
