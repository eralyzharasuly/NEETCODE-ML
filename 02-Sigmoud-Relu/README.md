# Sigmoid & ReLU

This project implements two fundamental activation functions used in Machine Learning.

## Sigmoid

Formula:

sigmoid(x) = 1 / (1 + e^(-x))

Example:

Input:
[-1, 0, 1]

Output:
[0.26894, 0.5, 0.73106]

## ReLU

Formula:

ReLU(x) = max(0, x)

Example:

Input:
[-1, 0, 1]

Output:
[0.0, 0.0, 1.0]
